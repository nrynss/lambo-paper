## Dense Retrieval and RAG

Standard Retrieval-Augmented Generation (Lewis et al., 2020) and memory-augmented systems (MemoryBank, Zhong et al., 2023) use dense vector representations. In software engineering tasks, these representations suffer from semantic drift when architectural constraints are updated or superseded.

## Graph-Augmented Retrieval

GraphRAG (Edge et al., 2024) and HippoRAG (Gutierrez et al., 2024, 2025) use graph indices to connect knowledge entities. However, these systems rely on batch indexing over static documents and Personalized PageRank. Lambo introduces an in-memory dynamic daemon that accepts live concurrent mutations, enforces directed edge priority traversal, and tracks earned canonization lifecycles.

## Autonomous Agents and Memory Architectures

Voyager (Wang et al., 2023) accumulates executable skill libraries, while Reflexion (Shinn et al., 2023) relies on verbal reflection buffers. MemGPT (Packer et al., 2023) establishes hierarchical operating system memory abstractions. Lambo builds upon these foundations by providing a shared, attributed topological substrate specifically tailored to multi-agent software engineering swarms.
