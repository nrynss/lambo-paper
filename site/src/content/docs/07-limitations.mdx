## 7.1 Multi-Repository Dispersion Effect

During longitudinal evaluation across 15,000 canonization cycles, zero concepts achieved Canonical status under the Swarm consensus policy. We formalized this as the **Multi-Repository Dispersion Effect**: when an operator works across $R$ independent repositories, corroborating citations are diluted across disjoint problem domains:
$$\mathbb{E}[\delta_r(c)] = \frac{\delta_{\text{base}}(c)}{R}$$

## 7.2 Text-Surface Affordance Gap

Telemetry revealed a 26.8% error rate on `lambo_inspect` on CUDA and 25.0% on Metal. The tool requires an exact UUID or substring. Because `lambo_recall` renders text content without node UUIDs, client models type approximate substrings from memory that fail to match. Future versions must surface explicit UUID handles in rendered context blocks.

## 7.3 Memory Compression on Unified Platforms

On Apple Silicon platforms under `launchd`, idle daemon processes experience aggressive memory compression (up to 1,417 MB compressed). Subsequent calls pay decompression penalties up to 9 seconds. Periodic lightweight heartbeat probes prevent aggressive OS paging.
